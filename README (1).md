# Evaluation protocols

Four written protocols, one per evaluation step. Each was written **before** the corresponding
runs and is deposited here afterwards; it is therefore *pre-specified* (not registered in an
external registry, and not time-stamped by a third party).

| File | Step | Date written |
|---|---|---|
| `PROTOCOL_SIMULATION.md` | Simulated corpora, variants V0--V5 | 2026-10-27 |
| `PROTOCOL_PIMA.md` | Pima Indians Diabetes, V0 and E3 | 2026-10-28 |
| `PROTOCOL_NHANES.md` | NHANES 2015--2016, three classes | 2026-10-28 |
| `PROTOCOL_CLASS_PRIOR.md` | Class-prior hypothesis, variants P1/P2 | 2026-10-28 |

The protocols were originally written in French and are translated here without changing their
content. The class-prior protocol was written after the Pima and NHANES results had been seen,
so its results are exploratory on those two data sets.
